Clipper

Clipper is a personal, non-commercial desktop tool used by the operator of the YouTube channel The Best Part to prepare short clips from long-form videos and to schedule them on that channel.

What it does

  • Finds self-contained moments in long videos the operator has the rights to use, and suggests titles, descriptions and thumbnails.
  • Every clip is reviewed and approved by hand before anything is sent to YouTube.
  • Uploads approved clips to the operator's own channel as private videos with a scheduled publication date, sets the thumbnail and adds them to a playlist.
  • Reads basic statistics (views, average view duration) of the channel's own clips to see which clips work best.

Clipper runs only on the operator's own computer. It is not offered to the public, has no user accounts and is used with a single YouTube channel.

Privacy Policy

Last updated: November 7, 2026

Who this applies to

Clipper is used only by its operator, with the operator's own Google account and YouTube channel. It does not collect data from anyone else.

Data accessed through YouTube API Services

With the operator's permission (Google OAuth), Clipper uses the YouTube Data API and the YouTube Analytics API to:

  • upload videos, set thumbnails and manage playlists on the operator's own channel;
  • list the channel's own recent uploads (to avoid uploading the same clip twice);
  • read view counts and average view duration of the channel's own videos.

Clipper does not access data about other YouTube users, viewers or channels, and does not read comments, subscribers or private messages.

How data is stored

  • All data stays on the operator's own computer, in a local database. Nothing is stored on a server.
  • The Google access token is stored locally and is never shared.
  • Statistics are kept only to compare the performance of the channel's own clips.

Sharing

YouTube data obtained through the API is never sold, shared with, or transferred to anyone. To find good moments and write titles, Clipper sends the audio and transcript of the source video being edited to a speech-to-text service (Deepgram) and a text AI service (Anthropic). No YouTube API data and no personal data about other people is sent to them.

Deleting data and revoking access

  • Access can be revoked at any time from Google Account → Security → Third-party access.
  • Deleting Clipper's data folder on the computer removes all stored data and the access token.
  • On request, all stored statistics about the channel's clips can be deleted at any time.

Google and YouTube policies

Clipper uses YouTube API Services. By using it, the operator agrees to the YouTube Terms of Service. See also the Google Privacy Policy.
